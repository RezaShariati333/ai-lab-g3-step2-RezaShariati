جمع‌آوری و بررسی داده‌ها

در این گام، مجموعه‌داده MovieLens Latest Small به‌عنوان منبع داده پروژه سیستم پیشنهاد فیلم انتخاب شد. این مجموعه‌داده توسط GroupLens ارائه شده و شامل اطلاعات فیلم‌ها و امتیازهایی است که کاربران به فیلم‌ها داده‌اند.

دو فایل اصلی مورد استفاده در این پروژه عبارت‌اند از:

movies.csv: شامل شناسه فیلم‌ها، عنوان آن‌ها و ژانرهای مربوط به هر فیلم.

ratings.csv: شامل شناسه کاربران، شناسه فیلم‌ها، امتیازهای ثبت‌شده و زمان ثبت امتیازها.

هدف از انتخاب این مجموعه‌داده، استفاده از اطلاعات واقعی برای شناخت فیلم‌ها و ترجیحات کاربران و فراهم کردن زمینه لازم برای طراحی سیستم پیشنهاددهنده است.

برای بررسی کیفیت و ساختار داده‌ها، موارد زیر در نظر گرفته شدند:

۱. بررسی نام ستون‌ها و نوع داده‌های هر ستون برای شناخت ساختار فایل‌ها.

۲. بررسی تعداد رکوردها، تعداد فیلم‌های موجود، تعداد کاربران و تعداد کل امتیازهای ثبت‌شده.

۳. بررسی مقادیر خالی برای شناسایی اطلاعات ناقص در داده‌ها.

۴. بررسی رکوردهای تکراری و شناسه‌های تکراری فیلم‌ها.

۵. بررسی اعتبار امتیازهای کاربران و اطمینان از قرار داشتن آن‌ها در محدوده مجاز.

۶. بررسی ارتباط شناسه فیلم‌ها در فایل امتیازها با شناسه‌های موجود در فایل اطلاعات فیلم‌ها.

۷. بررسی آماری امتیازهای کاربران و شناخت فراوانی ژانرهای مختلف فیلم.

در پایان این گام، ساختار داده‌ها و روش بررسی کیفیت آن‌ها مشخص شد. نتایج بررسی‌ها می‌توانند در مرحله پیش‌پردازش برای شناسایی مشکلات احتمالی و آماده‌سازی داده‌ها مورد استفاده قرار گیرند.
